## Teacher selection and gate interpretation

The campaign selected `T-WB-METRIC` using val-select PESQ only:

```text
T-WB-BASE   1.585530
T-WB-METRIC 1.586171
delta       +0.000641
```

On the held-out test subset, the paired aggregate delta was -0.010722 PESQ.
This discrepancy is recorded as a warning. It must not be used for
post-hoc hyperparameter selection because that would leak the test split.
The pilot is too small and has only one seed, so it cannot establish or reject
the scientific hypothesis. The predeclared full experiment is the next valid
measurement.
