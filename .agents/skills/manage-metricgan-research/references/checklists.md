# Checklists

## Code/config change

- Identify affected architecture block and cause.
- Check worktree and historical compatibility.
- Add/update tests.
- Run focused tests, then full unit suite.
- Run real entry-point smoke.
- Update architecture hash baseline if relevant.
- Run project guard.
- Summarize invalidated runs/claims.

## Training

- Clean committed snapshot.
- Unique run ID.
- Resolved config and exact command.
- Frozen manifest hashes and split audit.
- Declared seed(s) and selection rule.
- New output root.
- Teacher ancestry and threshold.
- Student/QAT gates.
- Final hold-out policy.
- Metrics, support, curves, model hashes.

## Cleanup

- Classify each target: canonical, duplicate, regenerable, failed, invalid,
  superseded, private or out-of-scope.
- Resolve exact paths and hashes.
- Preserve the concise lesson and recoverability reference.
- Verify no unique valid evidence would be lost.
- Obtain explicit deletion authority.
- Re-run documentation index, project guard and tests.

## Documentation/article

- One owner per fact.
- Index every canonical document.
- Mark evidence status.
- Remove or label stale values.
- Trace table cells to raw metrics.
- State seeds, support and uncertainty.
- Update limitations and unresolved questions.
